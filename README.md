# Navigation System for Public Transportation

A smart navigation system for public transportation that utilises real-world map data to explore route optimisation under simulated traffic conditions. The project investigates graph algorithms, dynamic routing, ride-sharing, and efficient transportation planning.

## Tech Stack

- React
- TypeScript
- Vite
- MapLibre GL JS
- OpenStreetMap
- Stadia Maps

## Features

- Interactive map visualisation
- Route optimisation using graph-based algorithms
- Simulated traffic conditions
- Dynamic routing exploration
- Ride-sharing and transportation planning concepts
- Real-world map integration using OpenStreetMap data

## Getting Started

### Prerequisites

Ensure you have the following installed:

- Node.js
- npm

### Installation

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/shukoray/public-transit-navigation-system.git
cd public-transit-navigation-system
npm install
```

### Run the Development Server

Start the local development server:

```bash
npm run dev
```

Then open the local development URL provided by Vite in your browser.

### Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
